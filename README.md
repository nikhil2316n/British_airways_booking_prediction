# British_airways_booking_prediction
Machine learning project using Random Forest to predict customer booking behaviour based on purchase timing, flight hour, and trip duration.
✈ British Airways Booking Prediction – Machine Learning Project

This project was completed as part of the British Airways Data Science Job Simulation on Forage (February 2026). The objective was to build a predictive model to identify factors influencing customer booking completion.

Using Python and Scikit-learn, a Random Forest classifier was developed to analyse customer booking data and uncover key drivers of buying behaviour.

🔍 Key Highlights:

Performed exploratory data analysis (EDA)

Applied feature engineering and one-hot encoding

Built and evaluated a Random Forest model

Conducted cross-validation

Extracted feature importance for model interpretation

Generated business insights to improve booking conversions

📊 Key Findings:

The most influential factors affecting booking behaviour were:

Purchase lead time

Flight hour

Length of stay

💡 Business Impact:

The findings suggest that early booking incentives, optimized pricing for high-conversion flight hours, and special packages for longer stays can help increase booking rates.
